# Metalúrgica Nano — Site

Projeto React + TypeScript com Vite, Tailwind CSS e React Router.

## Scripts

- `dev`: inicia o servidor de desenvolvimento
- `build`: compila para produção
- `preview`: pré-visualiza o build
- `lint`: verifica lint
- `format`: formata o código com Prettier

## Como usar

1. Instale as dependências:

```sh
npm install
```

2. Rode o projeto:

```sh
npm run dev
```

Abra o endereço indicado pelo Vite no navegador.

## Estrutura principal

- Rotas em `src/routes/router.tsx`
- Layout em `src/layouts/RootLayout.tsx`
- Páginas em `src/pages/*`
- Componentes em `src/components/*`
- Estilos Tailwind em `src/styles/globals.css`

## Tailwind

Tokens de cores (primária, accent e steel) configurados em `tailwind.config.js`.

## SEO básico

`index.html` contém título, descrição e favicon (placeholder). Substitua por ativos reais quando necessário.
